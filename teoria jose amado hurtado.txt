1.Define con tus palabras qué es una base de datos. (2 pts)
Es un conjunto de informacion agrupada de forma logica y/o ordenada.

2.Menciona dos diferencias entre bases de datos relacionales y NoSQL. (2 pts)
En las relacionales se utilizan tablas para agupar la informnacion en las sql se usan documentos
En las relacionales se usa relaciones entre las tablas en las nosql no es necesario usa relaciones ya que no se usa tablas.

Con MySQL se puede accededr a los datos mediante instrucciones hacia tablas y relaciones entre ellas. Se puede usar para una escuela primaria.
Con Mongo se pueded acceder a los datos mediante instrucciones mongo en documentos. se puede usar en apps big data con datos muy cambiables y campos dinamicos

4.¿Qué representa un modelo entidad-relación y qué elementos lo componen? (2 pts)
Es una representacion grafica de como se relacionana las tablas o entidades en una base relacional, se compone por llaves primarias y llaves foraneas

Es la forma de particionar la informacion en campos para ser mas entendible y manejable

La clave foranea es un identificador establece la relaciona en dos tablas
